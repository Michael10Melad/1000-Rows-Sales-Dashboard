# Sales Dashboard Project

## 📊 Project Overview

This project is an interactive dashboard created using Microsoft Excel to analyze and visualize 100 rows of sales data in a clear and simple way.

## 🛠️ Tools & Technologies

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Data Analysis
* Data Visualization
* Dashboard Design

## 📈 Dashboard Features

* Sales performance analysis
* KPIs and summary statistics
* Sales analysis by product and category
* Sales analysis by sales representative
* Customer, gender, and city analysis
* Time-based sales analysis
* Charts and visualizations
* User-friendly dashboard layout

## 🎯 Project Purpose

The main goal of this project is to practice data analysis and dashboard creation using Excel and transform sales data into useful and easy-to-understand visual insights.
